# تحدي المليون

مشروع لعبة مسابقات عربية مستوحاة من فكرة "من سيربح المليون". اختبر معلوماتك واربح المليون الوهمي!

## المميزات الرئيسية
- 15 مستوى من الأسئلة متدرجة الصعوبة لضمان تجربة مثيرة.
- وسائل مساعدة: حذف إجابتين (50:50)، الاتصال بصديق، سؤال الجمهور.
- واجهة مستخدم احترافية وتفاعلية مع رسوم متحركة ممتعة.
- دعم اختصارات لوحة المفاتيح لتسهيل اللعب.
- وضع المقدم (Presenter Mode) للتحكم باللعبة في الفعاليات والعروض الحية.

## طريقة التشغيل
1. قم بفتح ملف `index.html` مباشرة في أي متصفح حديث (مثل Chrome, Edge, Safari).
2. **ملاحظة هامة:** لضمان عمل اللعبة بشكل سليم وقراءة ملفات البيانات (JSON) دون مشاكل الـ CORS، يُفضل استخدام خادم محلي (Local Server):
   - عبر إضافة `Live Server` في VSCode.
   - أو بفتح موجه الأوامر في مجلد المشروع وتشغيل الأمر: `python -m http.server`.

## طريقة إضافة أسئلة جديدة
- **عبر لوحة التحكم**: يمكنك إضافتها إذا كان النظام يدعم واجهة للإدارة.
- **تعديل الملف يدوياً**: 
  1. قم بفتح ملف `data/questions.json` باستخدام أي محرر نصوص.
  2. أضف كائن JSON جديد يحتوي على السؤال، الخيارات، الإجابة الصحيحة، ومستوى الصعوبة (من 1 إلى 15).

## طريقة تعديل سلم الجوائز
افتح ملف `data/settings.json` وقم بتعديل مصفوفة `prizes`. 
تأكد من وجود 15 قيمة مرتبة من الأصغر للأكبر. يمكنك أيضاً تغيير العملة بتعديل الحقل `currency`.

## طريقة استبدال الأصوات
لتبديل الموسيقى والمؤثرات الصوتية، استبدل ملفات الصوت الموجودة في مجلد `assets/audio/` مع الاحتفاظ بنفس أسماء الملفات وصيغها لتجنب مشاكل التشغيل.

## اختصارات لوحة المفاتيح
- `1, 2, 3, 4` : لاختيار الإجابات A, B, C, D
- `Enter` : لتأكيد الإجابة النهائية
- `f` : وسيلة حذف إجابتين (50:50)
- `p` : وسيلة الاتصال بصديق
- `a` : وسيلة سؤال الجمهور
- `n` : الانتقال للسؤال التالي بعد الإجابة الصحيحة
- `مسافة (Space)` : تشغيل/إيقاف المؤقت (حسب إعدادات اللعبة)
- `m` : كتم/إلغاء كتم الصوت
- `F11` : تبديل وضع ملء الشاشة
- `Escape` : إغلاق النوافذ المنبثقة
- `F8` : فتح لوحة تحكم المقدم (إذا كانت مفعلة)

## وضع المقدم
يمكن تفعيل وضع المقدم لتسهيل إدارة اللعبة أثناء العروض الحية والمسابقات الجماعية. يتم الوصول للوحة التحكم بالضغط على مفتاح `F8`. يسمح هذا الوضع للمقدم بالتحكم الكامل في مجريات اللعبة وعرض الإجابات والمؤثرات يدوياً.

## الهيكل التنظيمي للمشروع
```
/
├── index.html          # الصفحة الرئيسية للعبة
├── README.md           # ملف التعليمات
├── css/
│   └── style.css       # ملفات التنسيق الأساسية
├── js/
│   └── main.js         # الكود البرمجي للعبة
└── data/
    ├── questions.json  # بنك الأسئلة (يحتوي على أكثر من 70 سؤالاً)
    └── settings.json   # إعدادات اللعبة وقيم الجوائز
```

## متطلبات التشغيل
- متصفح ويب حديث (يدعم ميزات HTML5 و CSS3 و ES6).
- خادم ويب محلي (Local Web Server) لقراءة ملفات البيانات بشكل صحيح.

## الرخصة
هذا المشروع مفتوح المصدر ومتاح للاستخدام والتعديل الشخصي والتجاري.
